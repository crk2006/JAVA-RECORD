## 📖 About the Project

**Java Lab Record** is a modern, responsive web-based interface designed to organize and present academic laboratory records digitally.

The website provides an easy-to-use interface where laboratory experiments can be organized according to different weeks. Students can quickly access their records, view documents, and track their laboratory progress.

The current interface contains **Week 1** and **Week 2** records and provides a document-viewing interface for laboratory materials.

## 🔄 Updating Laboratory Records

To add a new week's laboratory record:

1. Add the PDF file to the `documents/` folder.
2. Update the week navigation in the HTML/JavaScript files.
3. Connect the new PDF to the document viewer.
4. Test the document locally.
5. Commit the changes.
6. Push the changes to GitHub.
7. GitHub Pages will automatically update the website.

Example:

```bash
git add .
git commit -m "Add Week 3 Java Lab Record"
git push origin main
```
